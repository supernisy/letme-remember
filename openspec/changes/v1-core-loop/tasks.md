- [x] 4.2 实现 `recall` 关键词检索 + 「相关度 × 权重 × 新鲜度」排序 + 时间衰减下限兜底；验证：构造一组条目，排序结果符合公式，且旧条目不会因衰减被彻底归零。

- [x] 4.4 实现读路径零模型调用、零网络依赖；验证：断网状态下 `recall` 仍正常返回结果，代码路径中无任何模型或网络调用。
- [x] 4.5 实现 `rebuild`：删掉索引目录后从真相源重建；验证：重建前后检索结果一致，索引文件不入库。
